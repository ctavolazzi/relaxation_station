## What we did

1. Reviewed, read-only, from throwaway clones: OpenUI (thesysdev/openui), awesome-design-patterns

3. Wrote `docs/roadmap.md`: the proposed path from the videos to the end game, in five phases with gates.

## What we found

- repowise indexed `_RDA` (231 files) in 22 seconds and `johnnyautoseed` (1,043 files) in 85, with no API
  key. Its doc-drift check flagged 28 rows in `johnnyautoseed/CODEBASE_MAP.md` that name files no longer in
  the repo, 1 in each repo's `CLAUDE.md` and 3 in `_RDA/brand.md`. All 17 flags in `PAGE_COMPONENT_MAP.md`
  were rows already marked retired, and 9 flags in `_RDA` were template placeholders. It found 0 decisions
  in either repo, so it does not read the decisions-log format.
- Default `repowise init` writes five config files into the repo, a git hook, and hooks into the user's
  global Claude Code settings. With `--no-editor-setup --no-hook` it writes only `.repowise/` (11 MB) and one
  `.gitignore` line.
- freellmapi is well built and candid, and its own docs limit it to personal, single-user use. OpenUI is a
  serious generative-UI framework with vendor-run benchmarks and a needed repair layer. The patterns list is
  127 links, no code, last touched October 2024.
