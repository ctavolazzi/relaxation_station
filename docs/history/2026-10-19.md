## Later still: the Workbench Cockpit

The host was not impressed by the companion page: "There's code here you're ignoring", and "Nothing to
really do". So the next build puts all four repos to work, each doing the job it was made for, in one page:
"Workbench Cockpit", a private page on claude.ai (https://claude.ai/artifact/YYjEQs4gzk2CFezqCPcegs).

- **repowise** indexed six repos offline, with a scrubbed environment and no API key: johnnyautoseed (121 s),
  _RDA (21 s), thecoffeejesus (13 s), relaxation_station (8 s), openui (185 s), freellmapi (122 s). The page
  shows its health scores, hotspots, dead code, fix queue, import graph and doc drift for every file.
- **freellmapi**'s own catalog script, run offline on its seed data, supplies the free-model table: 108
  models, 15 providers, and each provider's terms verdict.
- **OpenUI** draws everything: its chat interface on one side, and eight cockpit screens written in OpenUI
  Lang on the other. The screens read live data through `Query()` calls to nine page functions; Claude
  answers chat questions by calling the same nine functions, and its answers are OpenUI cards whose buttons
  open files and views in the cockpit.
- **awesome-design-patterns** became a searchable reading shelf (122 entries, links not checked).
- A **stale-reference fixer**: pick a doc, choose per line (strike through, remove, or leave), preview the
  diff, then download the fixed file or copy the edits as instructions for Claude Code.

Tests run on 2026-10-19:

- The nine screens against OpenUI's own parser: 9 of 9 clean; planted bad programs are caught.
- The fixer on all 13 docs with stale lines: choosing "leave" everywhere returns each file byte for byte,
  and every untouched line survives in order.
- Headless Chromium with a stand-in for Claude that really calls the page tools: 16 of 16 steps pass, no
  console errors. Covered: every screen, search and filters, inspect and back, the fixer download (matches
  the fixer's own output exactly), a chat answer whose buttons drive the cockpit, a refusal message, phone
  width with no sideways scroll, and dark mode.
- Not tested: real Claude answers and the real download prompt. Those only run on the published page.

  called out.

  opened on the wrong tab, so the cockpit screens use plain sections instead.
- The repowise export swapped dashes for " , ", which read badly on screen until a cleanup pass.
- Earlier in the day, the freellmapi and OpenUI installs and test runs used the normal shell environment,
  which holds the session's GitHub and cloud tokens. Everything third-party has run with a scrubbed
  environment since. OpenUI's install script also sends an anonymous install ping unless DO_NOT_TRACK is set;
  it ran once.
